# tests 开发约定

适用范围：`tests/`。同时遵守根 `AGENTS.md`；业务规则见 `src/AGENTS.md`。

- 使用隔离的内存数据库或独立临时数据目录；不读取或覆盖宿主生产数据库。
- 覆盖用户/平台隔离、权限边界、去重、无候选、输入校验、并发预留和随机结果范围。图库 MIME 按文件头验证，不能假设文件扩展名正确。
- 关键词测试应经真实消息处理链与插件生命周期执行，并验证旧命令不再注册；不能仅复制业务逻辑验证自身。
- 保留目录说明清单守卫，检查根 AGENTS 登记的每个子目录说明都存在且无漏项。
- sandbox 验证使用专属测试群和用户，凭证只在运行时提供，报告不记录 token。

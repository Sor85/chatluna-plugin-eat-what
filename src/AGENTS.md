# src 开发约定

适用范围：`src/` 服务端实现。同时遵守根 `AGENTS.md`；验证约定见 `tests/AGENTS.md`。

- 入口只声明配置、依赖和挂载逻辑；推荐历史集中在 service，仅通过关键词触发。不提供 eat、drink 命令或命令开关。
- 关键词通过带原始消息精确过滤的 `$processor.match` 注册，在宿主 attach 检查之后、AI 分发之前回复。普通 middleware 可能被较早注册的 AI 管线吞掉，prepend 又会绕过 attach 检查；禁止用这两者代替 matcher（见 keywords.ts 与消息链回归测试）。
- 去重按平台和用户隔离，同一用户跨群共享历史；食物、饮料分池且共用一小时重置时间。候选耗尽后只重置对应池，历史不持久化。
- 图库是随包发布的只读资源，不操作宿主数据库，不调用外部模型或网络服务。
- 图片路径只从随包图库解析，不接受用户指定路径。正确区分 JPEG/PNG；模板只替换 image、dishes 占位符，不求值。
- 以平台回复元素输出用户文本，不将食物名称拼接为消息标记执行。
- 配置保留在 Config Schema，由宿主原生插件表单编辑；不注册自定义管理页面或图片预览接口。
- 不复制旧插件实现；按公开功能契约重写。复用有许可的数据时保留来源和许可。

# chatluna-plugin-eat-what

`chatluna-plugin-eat-what` 是适用于 ChatLuna V2 的吃喝图片推荐插件。

## 功能

- 精确匹配「吃什么」「喝什么」，随机回复图片及名称。
- 67 张普通食物、85 张普通饮料；可分别加入 15 张额外食物、1 张额外饮料。
- 自定义关键词和回复模板，支持 `{{image}}`、`{{dishes}}`。
- 同一平台用户共用一小时窗口，食品、饮品分别去重；某类候选抽完后立即重置该类。插件重启清空历史，不保证抽完后仍不重复。

这是娱乐性图片推荐，部分普通图库也包含猎奇内容；关闭额外图库不代表全部图片适合食用或饮用。

## 配置

在 V2「插件管理」中启用 `chatluna-plugin-eat-what`，通过宿主原生表单修改配置。

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `useKeyword` | `true` | 开启精确关键词匹配 |
| `useExtraFoods` | `false` | 食物池加入额外图库 |
| `useExtraDrinks` | `false` | 饮料池加入额外图库 |
| `foodsKeyword` | `["吃什么"]` | 食物关键词 |
| `drinksKeyword` | `["喝什么"]` | 饮料关键词 |
| `foodsTemplate` | `{{image}}\n建议{{dishes}}` | 食物回复模板 |
| `drinksTemplate` | `{{image}}\n建议{{dishes}}` | 饮料回复模板 |

关键词按完整消息匹配，不自动去空白，不把「今天吃什么」视为「吃什么」；冲突时食物优先。插件遵循宿主作用域筛选，忽略机器人自身消息。

模板的普通文本和菜名会转为文本消息元素；不执行模板表达式，也不将 `<at>`、`<img>` 等文本解释为消息标记。未知占位符保持原样。可以只使用 `{{dishes}}` 发送纯文字。
